WildernessRegen is now called Rewild. This release renames it and changes nothing else in how it works. The owner chose the name on 2026-11-08.

This is an early 0.x release. It has passed bot tests on throwaway servers; no real game client was involved.

## Upgrading from WildernessRegen 0.1.0

- Swap `WildernessRegen-0.1.0.jar` for `Rewild-0.2.0.jar` with the server stopped.
- On first start, `plugins/WildernessRegen/` is **moved** to `plugins/Rewild/` if that doesn't exist yet. It's a move rather than a copy because the folder holds undo backups of region files, which can be large, and an approved run must live in one place. Runs, undo backups, tracked chunks and settings come across unchanged. If the move fails, Rewild turns itself off and nothing resets until you rename the folder by hand. If both folders exist, `plugins/Rewild/` is used and the old one is ignored.
- **Deprecated, removed in the next release:** the command `/wr` (and `/wildernessregen`) and the permission `wildernessregen.admin`. They still work in 0.2.x and log a line saying what to use instead: `/rewild` and `rewild.admin`.
- Changed outright: the plugin, jar and folder are `Rewild`, the BlueMap layer is labelled Rewild, and the plugin API is `com.extantape.rewild.api.KeepProvider`. No published plugin registered a provider under the old name.
